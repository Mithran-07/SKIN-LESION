# Data Directory

This directory holds all raw and processed dermoscopic image data.
**Raw data is never committed to version control** (see `.gitignore`).

## Expected Structure

```
data/
├── raw/
│   └── HAM10000/
│       ├── HAM10000_metadata.csv
│       ├── HAM10000_images_part_1/   ← JPEG images
│       └── HAM10000_images_part_2/   ← JPEG images
├── train/                             ← Generated by preprocessing script
├── val/
└── test/
```

## Dataset Download (Phase 3)

Dataset download and preprocessing will be implemented in **Phase 3**.
Until then:

1. Register at [ISIC Archive](https://www.isic-archive.com/).
2. Download the **HAM10000** dataset.
3. Extract into `data/raw/HAM10000/` matching the structure above.
4. Update `config/config.yaml` → `dataset.root` accordingly.
