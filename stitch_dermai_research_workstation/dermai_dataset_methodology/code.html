Patient-Aware Splitting

To prevent data leakage, images are grouped by `lesion_id` before splitting. A model evaluating an image of a lesion it has seen from a different angle during training produces artificially inflated accuracy metrics.

Focal Loss Integration

Standard Cross-Entropy is overwhelmed by the NV class. We apply Focal Loss (\(\gamma = 2.0\)) dynamically weighted by inverse class frequencies to force the network to prioritize hard-to-classify minority examples. 

def compute_class_weights(labels):
    counts = np.bincount(labels)
    total = len(labels)
    # Inverse frequency weighting
    weights = total / (len(counts) * counts)
    
    # Normalize for stability
    weights = weights / np.sum(weights)
    return torch.FloatTensor(weights)

# Applied to Criterion
criterion = FocalLoss(gamma=2.0, alpha=class_weights)
